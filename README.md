**Gemini Web Translator** არის უახლესი თაობის, ულტრა-სწრაფი ბრაუზერის გაფართოება (Google Chrome, Brave, Microsoft Edge), რომელიც იყენებს **Google Gemini 3.8 & 3.5 Flash**-ის ხელოვნურ ინტელექტს. 

შექმნილია სპეციალურად **ქართულ ენაზე უმაღლესი ხარისხის, ბუნებრივი და იდიომატური თარგმნისთვის**, როგორც მონიშნული ტექსტებისთვის, ისე **მთლიანი ვებ-გვერდებისთვის**.

---

## ✨ ძირითადი შესაძლებლობები (Features)

### 1. 🌐 მთლიანი გვერდის თარგმნა (Full Webpage Translation)
* **DOM TreeWalker არქიტექტურა:** თარგმნის მხოლოდ ტექსტურ კვანძებს (Text Nodes). გვერდის დიზაინი (CSS), განლაგება (Layout), ღილაკები, ბმულები (`<a>`), კოდის ბლოკები (`<code>`, `<pre>`) და სკრიპტები რჩება 100% უცვლელი.
* **პარალელური Batch დამუშავება:** გვერდის შინაარსი იყოფა ოპტიმალურ ბლოკებად და მუშავდება პარალელურად, რაც უზრუნველყოფს მთლიანი სტატიების წამებში გადათარგმნას.
* **მცურავი პროგრეს-პანელი (Floating Top Banner):** აჩვენებს თარგმნის პროგრესს რეალურ დროში (0% → 100%).
* **1-Click Restore (0ms):** ღილაკი **„ორიგინალის ჩვენება“** წამის მეასედში აბრუნებს საიტის პირვანდელ უცხოურ ტექსტს გვერდის გადატვირთვის გარეშე!

### 2. ⚡ რეალურ დროში სტრიმინგი (Real-Time SSE Streaming)
* Server-Sent Events (SSE) ტექნოლოგიით პირველი ქართული სიტყვა ეკრანზე ჩნდება **200–300 მილიწამში**.
* ტექსტი იწერება სიტყვა-სიტყვით, ცოცხლად და შეუფერხებლად.

### 3. 🧠 ოპტიმიზებული დაბალი ლატენტობა (Thinking Optimization)
* Gemini 3-ის ნაგულისხმევი 4-7 წამიანი „ფიქრის რეჟიმი“ (Chain-of-Thought) თარგმნისთვის დაყვანილია მინიმუმამდე (`thinkingLevel: LOW / MINIMAL`), რაც უზრუნველყოფს მომენტალურ რეაგირებას.

### 4. 🛡️ ჭკვიანი Multi-Model Failover კასკადი
* თუ კონკრეტული მოდელი (მაგ. `gemini-3.8-flash`) Google-ის მხარეს გადატვირთულია (High Demand Spikes), სისტემა ავტომატურად გადადის ულტრა-სწრაფ სარეზერვო მოდელზე (**`gemini-3.5-flash-lite`**).

### 5. 💾 ლოკალური LRU Cache (0ms მყისიერი პასუხი)
* ადრე ნათარგმნი წინადადებები და აბზაცები ინახება ლოკალურ მეხსიერებაში. განმეორებითი თარგმნისას პასუხი გამოდის **0 მილიწამში**, ყოველგვარი ინტერნეტ-ტრაფიკისა და API კვოტის ხარჯვის გარეშე.

### 6. 🇬🇪 ელიტური ქართული ენობრივი სტანდარტი (System Prompt)
* **სუფთა გამონატანი:** არანაირი ზედმეტი შესავალი ტექსტები ("Here is the translation:").
* **ანტიკალკი:** ქართული ენის ბუნებრივი სინტაქსი და სწორი ერგატიული კონსტრუქციები.
* **ქართული ტიპოგრაფია:** ავთენტური ქართული ბრჭყალები („...“).
* **IT ტერმინოლოგია:** უცხოური აკრონიმებისა და ბრენდების სწორი ბრუნება დეფისით (API-ს, CI/CD-ის, Docker-ის, AWS-ზე).

### 7. 🔒 უსაფრთხოება და კონფიდენციალურობა (Privacy Guard)
* პაროლის ველებიდან (`type="password"`) და მგრძნობიარე ელემენტებიდან ტექსტის აღება ავტომატურად დაბლოკილია.
* თქვენი API Key ინახება **მხოლოდ თქვენს ლოკალურ ბრაუზერში** (`chrome.storage.sync`) და არასდროს იგზავნება მესამე მხარესთან.

## 🚀 ინსტალაციის ინსტრუქცია (1 წუთში)

### ნაბიჯი 1: პროექტის გადმოწერა
დააკლონეთ ეს რეპოზიტორი ან გადმოწერეთ ZIP არქივის სახით:
```bash
git clone https://github.com/lasha-kvara/gemini-web-translator.git
```

### ნაბიჯი 2: ექსთენშენის ჩატვირთვა ბრაუზერში
1. გახსენით **Google Chrome**, **Brave** ან **Microsoft Edge**.
2. მისამართების ველში ჩაწერეთ:
   * Chrome: `chrome://extensions`
   * Brave: `brave://extensions`
   * Edge: `edge://extensions`
3. მარჯვენა ზედა კუთხეში ჩართეთ **Developer mode** (დეველოპერის რეჟიმი).
4. დააჭირეთ მარცხენა ზედა ღილაკს **Load unpacked** (შეუფუთავის ჩატვირთვა).
5. მონიშნეთ და აირჩიეთ გადმოწერილი ფოლდერი `gemini-web-translator`.

🎉 **ექსთენშენი წარმატებით დაყენებულია!**

## 🔑 Gemini API Key-ს გააქტიურება

ექსთენშენს სჭირდება Google Gemini-ის პირადი API Key (Google AI Studio-ს უფასო ტარიფი სრულიად საკმარისია):

1. შედით [Google AI Studio-ზე](https://aistudio.google.com/app/apikey) და დააჭირეთ **Create API key**.
2. დააკოპირეთ მიღებული გასაღები (იწყება `AIzaSy...`-ით).
3. ბრაუზერში დააჭირეთ ექსთენშენის აიქონს -> **⚙️ პარამეტრები** (ან მარჯვენა კლიკით -> Options).
4. ჩასვით API Key, დააჭირეთ **„ტესტირება“** (დარწმუნდით, რომ მწვანედ დაგიწერთ წარმატებას) და დააჭირეთ **„💾 შენახვა“**.

> [!NOTE]
> თქვენი API Key ინახება უსაფრთხოდ თქვენივე ბრაუზერის ლოკალურ მეხსიერებაში. ის არ ხვდება კოდში და არ იგზავნება არცერთ გარე სერვერზე Google-ის ოფიციალური API-ს გარდა.
